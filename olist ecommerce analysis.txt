PHASE 6 - CREATING THE ANALYSIS DATASET
Objective:
Create one combined, analysis-ready dataset by merging the cleaned Olist datasets needed for business analysis.
Steps Completed:
1. Created a copy of orders_df
   . Created analysis_df so the original cleaned orders dataset would not be modified.
   . Initial size:99,441 rows,8 columns
2. Merged Customers
   .Merged using customer_id.
   .Result:99,441 rows, 12 columns
   .Missing customer IDs after the merge:0
3. Merged Order Items
   .Merged using order_id.
   .The number of rows increased because one order can contain multiple products.
   .Result before removing unmatched rows:113,425 rows,14 columns.
   .This increase was expected because Order Items contains multiple items for some orders.
4. Checked Order Items
   .Found 775 rows without product_id.
   .Found 775 rows without seller_id.
   .These represented order-level records that had no matching item information.
5. Merged Products
   .Merged using product_id.
   .Product information was added without creating unwanted duplicate item rows.
   .Some product category information was missing, which was retained rather than deleting the affected products.
6. Merged Sellers
   .Merged using seller_id.
   .Seller information was added to the analysis dataset.
7. Processed Payments
   .Payments were aggregated by order_id first before merging.
   .This was necessary because some orders have multiple payment records.
   .Aggregating first prevents the payment merge from unnecessarily multiplying rows and causing revenue overcounting.
8.Merged Category Translation
   .Standardized product_category_name.
   .Added the English category names using the category translation dataset.
9.Removed unmatched order-level rows
   .Since the main analysis is item-level, the 775 rows without product_id were removed.
   .Code used:analysis_df.dropna(subset=["product_id"])
Final Dataset
Final size:112,650 rows, 31 columns
The final analysis_df contains information from:
Orders, Customers, Order Items, Products, Sellers, Payments, Category Translation
Output File
The final dataset was saved as:Olist_analysis_dataset.csv
